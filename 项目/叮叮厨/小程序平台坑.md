# 叮叮厨 · 微信小程序平台坑

Taro 4.2.1 + React 18 编译到微信小程序（webpack5，webpack 锁 ~5.95.0）。下面这些不是 Taro 的问题，是小程序运行时的硬限制，写界面时会反复撞上。

## WXSS 不支持的语法

| 不支持 | 替代写法 |
| --- | --- |
| `flex-wrap` | 行容器 + 百分比宽度，自己排两行 |
| `calc()` | 提前在 JS 里算好，或用固定值 + 弹性项 |
| flexbox 的 `gap` | 用子元素 `margin` |
| `*` 通配符 | `box-sizing` 之类按元素选择器逐个写 |
| 直接写 emoji 字面量 | Unicode 转义，例如 `'\u{1F37D}\uFE0F}'` |

另外 `Text` 是行内元素，需要块级行为时外层套 `View`。

## 样式与令牌

- SCSS 引用主题令牌用 `@use '…/theme.scss' as *;`。`@import` 已被 Dart Sass 弃用，构建会报警告。
- 布局按行优先设计，不要指望换行能力。

## 构建与提审

- `app.config.ts` 必须开 `lazyCodeLoading: 'requiredComponents'`，组件按需注入是上传审核项。
- `project.config.json` 有根目录和 `dist/` 两份，要同步保持一致：真实 appid、`miniprogramRoot: "dist/"`、`setting.minified/minifyWXSS/minifyWXML: true`。
- 产物 `dist/` 压缩后约 640K，主包 2M 限额内还有余量。

## 环境变量

- Taro 只注入 `TARO_APP_*` 前缀的变量，其它名字在客户端读不到。
- `dev:weapp` 载入 `.env.development`，`build:weapp` 载入 `.env.production`；改完 `.env` 必须重新构建才生效，不是热更新。
- Umi 侧（管理后台）同理只读自己目录下的 `.env`，不读 monorepo 根目录那份；根目录 `.env` 只服务于 docker compose。

## 与后端联调

- WS 地址必须是 `ws://`/`wss://` 前缀，写成 `http://` 会静默失败并回退本地规则回答，看起来"一切正常"。
- 生产链路必须 https/wss，且域名进小程序后台合法域名列表（详见[云托管部署](云托管部署.md)）。
- 被 gate 的页面不要自动跳登录，显示缺省页 + 「去登录」按钮；自动重定向会导致返回时白屏。
