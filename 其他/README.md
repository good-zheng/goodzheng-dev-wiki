# 其他

跨项目复用的沉淀，目前只有 `skills/`。

和 `项目/` 的分工：带项目上下文的架构、链路、部署笔记进 `项目/<项目名>/`；能被任意项目直接拿去用的方法论进这里。

## skills

每个 Skill 一个独立目录，目录内 `SKILL.md` 描述用途、触发时机与执行步骤，可按需附带 `examples.md`、`STANDARDS.md` 等补充文件。完整的分类导航与两步定位法见[仓库首页](../README.md)。

新增 Skill 的归位三步：建目录 → 判问题类型（工作流 / 问题排查 / 编码辅助）→ 判技术栈（通用 / 前端 / 后端 / 其他），然后挂到首页导航表对应位置。
